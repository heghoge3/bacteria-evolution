# «Бактерии» — план разработки (финальный, v1.0)

Нейро-эволюционная песочница: бактерии с собственными нейросетями с нуля учатся
двигаться к еде, есть её и размножаться. Цель первого этапа — **максимально простая,
но полностью рабочая база** с подробной статистикой, архитектура которой заранее
готова к постоянным расширениям (хищники, виды, яд и т. д.).

---

## 1. Как бактерии «учатся»

Обучение — **эволюционное**, а не в течение жизни:

1. В начале мозги (веса нейросетей) полностью случайные.
2. Жизнь и движение тратят энергию; от голода или старости бактерия умирает.
3. Съев нужное количество еды, бактерия делится: потомок получает **копию мозга с
   небольшими случайными отклонениями (мутациями)**.
4. Удачные мозги дают больше потомков, неудачные исчезают. Из поколения в поколение
   популяция «умнеет».

Важно: в базовой версии отдельная бактерия за жизнь **не меняет** свой мозг — умнеет
популяция (потомки чуть отличаются от родителей, и отбор оставляет лучших). Обучение
в течение жизни — отдельное расширение из бэклога (раздел 9).

## 2. Формат и технологии

**Выбор: веб-приложение, которое открывается как отдельное окно-программа.**

- Windows 11 всегда содержит браузер Edge. `Bacteria.bat` запускает его в режиме
  приложения: `start msedge --app="%~dp0app\index.html"` — отдельное окно без адресной
  строки и вкладок, выглядит как обычная программа. Ничего устанавливать не нужно.
- Это самый быстрый и экономный путь; настоящий `.exe` (Tauri) можно сделать позже
  без переписывания кода.

| Что | Чем |
|---|---|
| Язык | TypeScript |
| Сборка | Vite + `vite-plugin-singlefile` → один файл `app/index.html` (работает с `file://`) |
| Отрисовка поля | Canvas 2D |
| Графики | uPlot (быстрые, лёгкие, тысячи точек) |
| UI | чистый TypeScript + CSS, без фреймворка |
| Тесты | Vitest + консольный «безголовый» прогон симуляции через Node |
| Сохранения | экспорт/импорт `.json` + автосейв в `localStorage`/IndexedDB |

Для пользователя: скачать архив (или GitHub Release) → распаковать → двойной клик по
`Bacteria.bat`. Собранная папка `app/` хранится в репозитории, Node нужен только для
разработки.

Симуляция в базе крутится в основном потоке с бюджетом времени на кадр (≈12 мс).
Вынос в Web Worker — позже, за тем же интерфейсом, если понадобится скорость.

## 3. Модель мира (база)

### 3.1 Поле
- Прямоугольник 1200 × 800 единиц, границы — стены (бактерия упирается и скользит).
- Время дискретное: 1 тик = восприятие → решение → движение → еда → энергия →
  деление → смерть.
- Детерминированный генератор случайных чисел с `seed` — любой прогон можно повторить.
- Пространственная сетка (spatial hash) для быстрого поиска ближайшей еды.

### 3.2 Еда
- Неподвижные точки, появляются в случайных координатах.
- Скорость появления и максимум на поле настраиваются.

### 3.3 Бактерия
Состояние: id, id родителя, поколение, id линии (родоначальника), позиция, угол,
скорость, энергия, возраст, максимальный возраст, съедено всего, съедено с последнего
деления, число потомков, цвет (наследуется с мутацией оттенка — видно «семьи»),
геном (мозг + черты).

- **Голод:** каждый тик −метаболизм − стоимость движения (∝ тяге²). Энергия ≤ 0 → смерть.
- **Старость:** возраст ≥ личного максимального возраста (задаётся при рождении со
  случайным разбросом) → смерть.
- **Еда:** касание еды → +энергия (с ограничением максимума), счётчики съеденного +1.
- **Деление:** съедено с последнего деления ≥ N **и** энергия ≥ порога → энергия делится
  пополам, потомок появляется рядом, счётчик обнуляется. При достижении лимита
  популяции деление откладывается.
- **Защита от вымирания:** если бактерий меньше минимума — добавляются новые
  случайные (отмечается в журнале и на графиках).

### 3.4 Значения по умолчанию (субъективные, всё настраивается в UI)

| Параметр | Значение |
|---|---|
| Размер поля | 1200 × 800 |
| Стартовая популяция | 60 |
| Минимум популяции (подсев случайных) | 10 |
| Лимит популяции | 1000 |
| Еды на поле максимум | 400 |
| Появление еды | 1 шт. за тик |
| Энергия от 1 еды | 40 |
| Стартовая / максимальная энергия | 100 / 200 |
| Метаболизм | 0.1 за тик |
| Стоимость движения | 0.08 × тяга² за тик |
| Макс. скорость / макс. поворот | 2 ед./тик / 0.15 рад/тик |
| Радиус бактерии / еды | 5 / 3 |
| Съесть для деления | 3 еды |
| Мин. энергия для деления | 60 |
| Макс. возраст | 3000 тиков ± 20 % |
| Радиус «зрения» | 150 |
| Мутация: доля изменяемых весов / сила σ | 10 % / 0.2 |
| Крупная мутация (вес заменяется случайным) | 1 % |

## 4. Мозг (база)

**Упрощённое зрение — 5 входов:**
1–2. Направление на ближайшую еду относительно взгляда: `sin(Δугла)`, `cos(Δугла)`
     (если еды в радиусе зрения нет — 0, 0).
3. Близость ближайшей еды: `1 − расстояние / радиус зрения` (нет еды → 0).
4. Своя энергия (0…1).
5. Смещение (константа 1).

**Сеть:** 5 → 6 скрытых (tanh) → 2 выхода.
- Выход 1 — поворот (tanh, −1…1).
- Выход 2 — тяга (sigmoid, 0…1).

**Мутации при делении:** каждый вес с вероятностью 10 % получает гауссов шум σ = 0.2;
с вероятностью 1 % заменяется случайным. Оттенок цвета слегка сдвигается.

## 5. Архитектура под расширения

Главный принцип: **новая механика = новый модуль, а не правка всего кода.**

```
/src
  /core
    rng.ts            детерминированный ГСЧ
    events.ts         шина событий: born, died(cause), ate, reseeded, configChanged…
    config.ts         схема параметров (значение, мин/макс, шаг, подпись, группа)
    spatial.ts        пространственная сетка
  /sim
    world.ts          хранит сущности, запускает конвейер систем
    entities.ts       базовая сущность + типы: Bacterium, Food (реестр видов)
    genome.ts         геном = мозг + наследуемые черты (Map), мутация, сериализация
    /brain
      brain.ts        интерфейс Brain: forward / clone / mutate / toJSON
      mlp.ts          полносвязная сеть (база)
    /sensors          реестр сенсоров: каждый объявляет число входов и fill()
      nearestFood.ts, energy.ts, bias.ts
    /actuators        реестр действий: turn.ts, thrust.ts
    /systems          конвейер тика, порядок задаётся списком
      foodSpawn, sense, think, move, eat, metabolism, reproduce, death, reseed
  /stats
    metrics.ts        реестр метрик: имя, расчёт, группа графика
    history.ts        кольцевые буферы + прореживание старой истории
  /ui
    renderer.ts, camera.ts, charts.ts, inspector.ts, settings.ts, journal.ts, app.ts
  /storage
    save.ts           версионированный формат + миграции старых сохранений
/tests                юнит-тесты + сценарий «популяция учится»
/scripts/headless.ts  прогон без UI из консоли
/app                  собранное приложение (index.html)
Bacteria.bat
```

Что это даёт в будущем:
- **Хищники / новые виды** — новый тип сущности + свои системы; вид — это набор
  сенсоров, действий и параметров.
- **Новое «зрение» (лучи, соседи, яд)** — новый сенсор в реестре; размер входа сети
  считается автоматически.
- **Новые действия (атака, выделение яда)** — новый актуатор.
- **Новые параметры** — одна строка в схеме конфигурации, панель настроек строится сама.
- **Новые графики** — одна запись в реестре метрик, график появляется сам.
- **Другие мозги (рекуррентные, NEAT, обучение при жизни)** — новая реализация
  интерфейса `Brain`.
- **Старые сохранения** не ломаются благодаря версиям и миграциям.

## 6. Статистика и интерфейс (база)

### 6.1 Экран
Поле слева (зум колесом, перетаскивание мышью), справа вкладки:
**Статистика · Графики · Инспектор · Настройки · Журнал.** Язык — русский.

Управление: старт/пауза, шаг на 1 тик, скорость ×1 / ×5 / ×20 / ×100 / «максимум»
(без отрисовки), сброс с новым seed. Раскраска бактерий: по семье / по энергии /
по поколению. Переключатель «показывать зрение».

### 6.2 Счётчики
Тик, реальная скорость (тиков/с), популяция, еда на поле, всего рождений, смертей
(от голода / от старости), максимальное и среднее поколение, живых семей, подсевов.

### 6.3 Графики
1. Популяция и количество еды.
2. Рождения и смерти за интервал (голод/старость раздельно).
3. Среднее и максимальное поколение.
4. Средняя энергия.
5. Средняя продолжительность жизни умерших.
6. **Эффективность:** еды съедено на бактерию за 1000 тиков — главный показатель «ума».
7. **Направленность:** средний косинус между движением и направлением на еду
   (случайные ≈ 0, обученные → 1).
8. Средняя скорость (тяга).
9. Доли 5 крупнейших семей.

### 6.4 Инспектор
Клик по бактерии: все её параметры; схема нейросети с живыми активациями (цвет — знак,
толщина — вес); линия к еде, которую она «видит»; кнопка «следить камерой».

### 6.5 Журнал и сохранения
Журнал: подсевы, рекорды поколений, вымирание крупных семей, изменения настроек.
Сохранить/загрузить мир целиком (с историей графиков), экспорт статистики в CSV.

## 7. Этапы разработки

| # | Этап | Критерий готовности |
|---|---|---|
| 1 | Каркас | Проект Vite + TS, сборка в один `app/index.html`, `Bacteria.bat` открывает окно |
| 2 | Ядро | ГСЧ с seed, шина событий, схема конфигурации, пространственная сетка, тесты |
| 3 | Мир и еда | Поле, камера, случайное появление еды |
| 4 | Бактерии | Движение, энергия, голод, старость, конвейер систем |
| 5 | Мозг | Сенсоры/актуаторы через реестры, MLP, мутации, геном |
| 6 | Размножение | Деление по N еды + энергия, наследование, лимит, подсев |
| 7 | Баланс | Консольный прогон: со случайного старта направленность > 0.6 и рост эффективности за ≤ 200 000 тиков |
| 8 | Статистика | Реестр метрик, история, все графики и счётчики |
| 9 | Инспектор и журнал | Клик по бактерии, схема сети, слежение, журнал |
| 10 | Сохранения | JSON-сохранение/загрузка с версией, CSV, автосейв |
| 11 | Полировка | Панель настроек из схемы, 1000 бактерий при 60 FPS на ×1, README с инструкцией |

Каждый этап — отдельный коммит; тесты и сборка проходят после каждого.

## 8. Риски

- **Мгновенное вымирание** → запас стартовой энергии, плотная еда, подсев случайных.
- **Взрыв популяции** → деление только после N еды, энергия пополам, лимит.
- **Стратегия «крутиться на месте»** → движение стоит энергию, еда разбросана.
- **Медленная работа** → пространственная сетка, режим «максимум» без отрисовки,
  при необходимости — Web Worker.

## 9. Бэклог (после базы)

Глаза-лучи и видимость соседей · обучение в течение жизни · рекуррентная память ·
NEAT · хищники и несколько видов · яд · еда «кустами» и сезоны · трупы → еда ·

тепловые карты · дерево родословной · отдельный `.exe` (Tauri).
