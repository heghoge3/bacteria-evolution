# Бактерии — нейро-эволюционная песочница

Бактерии с собственными нейросетями **с нуля** учатся находить еду и размножаться.
Никто не учит их напрямую: работает естественный отбор. Съел 3 еды → поделился →
потомок получил копию мозга с небольшими мутациями. Кто случайно ехал к еде, тот
размножился, остальные вымерли.

## Запуск (Windows 11)

Двойной клик по **`Bacteria.bat`** — откроется отдельное окно программы. Ничего
устанавливать не нужно (используется Microsoft Edge, он есть в Windows 11).
Если .bat не подходит — просто откройте `app/index.html` в любом браузере.

## Как пользоваться

- **Пуск/пауза** (пробел), **Шаг** — один тик, скорость **×1 … ×100 и «макс»**
  (при «макс» поле рисуется реже, расчёт идёт на полной скорости).
- Колесо мыши — зум, перетаскивание — сдвиг поля, ⤢ — вписать поле в окно.
- Клик по бактерии — **Инспектор**: параметры и живая схема нейросети
  (синие связи — положительные веса, оранжевые — отрицательные, цвет узла — активация).
  Галочка «следить» — камера едет за выбранной бактерией.
- **Статистика** — счётчики (тик, популяция, поколения, смерти, семьи…).
- **Графики** — 9 графиков истории; главный — «Направленность на еду»
  (≈0 — движутся случайно, →1 — едут прямо к еде). Старая история автоматически
  прореживается, так что можно смотреть весь запуск.
- **Настройки** — все параметры мира, еды, бактерий, деления и мутаций (значения по
  умолчанию подобраны на глаз). Параметры с ↻ применяются при новом запуске,
  остальные — на лету.
- **Журнал** — подсевы, рекорды поколений, вымирание семей, смена настроек.
- **Сохранить / Загрузить** — весь мир вместе с историей в `.json`; **CSV** — таблица
  статистики. Мир также автоматически сохраняется в браузере каждые 30 секунд.

Что вы должны увидеть: со случайного старта уже через 1–2 тысячи тиков (×100 — секунды)
направленность поднимается с ≈0 до 0.6–0.7.

## Разработка

Нужен Node.js 20+.

```
npm install
npm run dev        # режим разработки
npm test           # тесты симуляции
npm run headless -- 100000 12345 foodPerTick=0.3   # прогон без интерфейса
npm run build      # пересобрать app/index.html
```

Структура и план: [PLAN.md](PLAN.md). Главное правило архитектуры — новая механика это
новый модуль, а не правка всего кода:

| Что добавить | Куда |
|---|---|
| параметр | строка в `src/core/config.ts` (панель настроек строится сама) |
| сенсор («зрение») | `src/sim/sensors/` — реестр `defaultSensors` |
| действие | `src/sim/actuators/` — реестр `defaultActuators` |
| шаг тика (хищники, яд…) | `src/sim/systems/` — список `defaultSystems` |
| другой мозг (память, NEAT) | реализовать `Brain` в `src/sim/brain/` |
| метрика и график | `src/stats/metrics.ts` + `src/ui/charts.ts` |
