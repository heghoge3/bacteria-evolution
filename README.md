# Бактерии — нейро-эволюционная песочница

Бактерии с собственными нейросетями **с нуля** учатся находить еду, выживать и
размножаться. Никто не учит их напрямую: работает естественный отбор. Съела достаточно →
поделилась → потомок получил копию мозга и тела с небольшими мутациями.

Мир специально сделан так, чтобы одной «правильной» стратегии не было: еда растёт
кустами, которые истощаются; зимой еды меньше; есть вязкие и токсичные зоны; большое тело
запасает больше энергии, но дороже двигается; дальнее зрение стоит энергии. Поэтому
популяция расслаивается на разные стратегии, и они меняются, когда меняются условия.

## Запуск (Windows 11)

Двойной клик по **`Bacteria.bat`** — откроется отдельное окно программы. Ничего
устанавливать не нужно (используется Microsoft Edge, он есть в Windows 11).
Если .bat не подходит — просто откройте `app/index.html` в любом браузере.

## Что где

**Поле.** Цвет бактерии — её **тип поведения** (легенда слева вверху):

| Цвет | Тип | Что делают |
|---|---|---|
| 🔴 красный | Стоячие | почти не двигаются, ждут еду |
| 🟡 жёлтый | Кружащие | прочёсывают местность петлями |
| 🔵 синий | Быстрые охотники | на полной скорости летят к еде |
| 🩵 бирюзовый | Охотники | спокойно едут к еде |
| ⚪ серый | Бродяги | двигаются без явной цели |

Клик по типу в легенде — **фокус**: остальные бактерии тускнеют, у выделенных видны следы.
Размер кружка — черта «размер». Пунктирные круги — зоны (синие — вязкие, фиолетовые —
токсичные), тонкие зелёные круги — кусты еды (ярче — богаче).
Колесо — зум, перетаскивание — сдвиг, клик по бактерии — инспектор.

**Вкладки справа:**
- **Статистика** — счётчики, время года, текущая эпоха.
- **Стратегии** — доли типов во времени и таблица стратегий: тип + до двух меток
  («крупные», «у стен», «в кустах еды», «ранние размножители»…). Для каждой — чем она
  отличается от среднего (зелёное — выше, оранжевое — ниже), кнопки «Показать» и 🔬.
- **Графики** — 14 графиков. Выделите участок мышью — приблизить; колесо — зум;
  Shift+колесо — сдвиг; двойной клик — вернуть окно. Кнопки 2k / 20k / 200k / Всё — окно
  времени для всех графиков сразу. Полоса вокруг линии — разброс (мин…макс), поэтому пики
  не пропадают даже в очень длинной истории. Пунктирные вертикальные линии — события
  (смена параметра, сценарий, новая стратегия, смена эпохи); наведите — появится подпись.
  Голубой фон — зима. ⤢ — график на весь экран.
- **Распределения** — тепловые карты: как распределена популяция по скорости, размеру,
  зрению и т.д. во времени. Две яркие полосы — популяция разделилась на две стратегии.
- **Хроника** — автоматический рассказ по эпохам + журнал событий.
- **Инспектор** — выбранная бактерия: тип и стратегия, черты тела, поведение, нейросеть
  с живыми активациями. Кнопка **🔬 В аквариум** — посмотреть на копию этой бактерии одну
  в маленьком мире, медленно и со следом.
- **Настройки** — пресеты (Лёгкий, Обычный, Суровый, Голод, Наблюдение, Классика v1),
  все параметры (↻ — только для нового запуска, остальные на лету) и **сценарий**:
  «на тике X поставить параметр Y = Z» + готовые шаблоны (кризис еды, похолодание…).
- **Запуски** — итоги всех завершённых запусков и сравнение их графиков.

**Выживание.** По умолчанию подсева нет: если популяция вымерла — запуск окончен и
показывается отчёт (что случилось, стратегии, хроника) с кнопками «Повторить (тот же
seed)» и «Новый seed». Кнопка «■ Завершить» — закончить запуск вручную. Подсев можно
включить в настройках («Песочница»).

**Сохранения.** «Сохранить / Загрузить» — весь мир с историей в `.json`; «CSV» —
таблица всех метрик. Мир автоматически сохраняется в браузере каждые 30 секунд.
Сохранения первой версии загружаются в режиме «Классика».

## Разработка

Нужен Node.js 20+.

```
npm install
npm run dev        # режим разработки
npm test           # тесты
npm run headless -- 60000 1 preset=harsh           # прогон без интерфейса с хроникой
npm run balance -- 8 60000 preset=normal           # подбор баланса по многим seed
npm run build      # пересобрать app/index.html
```

План: [PLAN.md](PLAN.md) (v1), [PLAN-2.md](PLAN-2.md) (v2). Главное правило
архитектуры — новая механика это новый модуль, а не правка всего кода:

| Что добавить | Куда |
|---|---|
| параметр | строка в `src/core/config.ts` (панель настроек строится сама) |
| черта тела | `src/sim/traits.ts` + её цена в `World.upkeepOf` и др. |
| сенсор | `src/sim/sensors/` — `buildSensors` |
| действие | `src/sim/actuators/` |
| шаг тика (хищники, яд…) | `src/sim/systems/` — список `defaultSystems` |
| другой мозг | реализовать `Brain` в `src/sim/brain/` |
| тип поведения / метка стратегии | `src/sim/behavior.ts` |
| метрика и график | `src/stats/metrics.ts` + `src/ui/charts.ts` |
| тепловая карта | `src/stats/heat.ts` |
